⚙️ Manual de Instalación: CapyControl (Backend)

Esta guía detalla paso a paso cómo desplegar el servidor central CapyControl en un entorno Windows usando XAMPP. Este sistema es el cerebro administrativo que gestiona el inventario, créditos y consolidación de todas las sucursales (CapyPOS).

1. Requisitos Previos

  • XAMPP con PHP 8.2 o superior y MySQL/MariaDB activados.
  • Composer instalado globalmente en el servidor.
  • Node.js y NPM instalados (para compilar los estilos y scripts del panel de control).

2. Despliegue de Archivos y Base de Datos

1

Copiar los archivos

Pega la carpeta entera del proyecto capycontrol dentro de la carpeta pública de tu servidor web (Usualmente C:\xampp\htdocs\capycontrol\).
2

Crear la Base de Datos Maestra

Abre phpMyAdmin (http://localhost/phpmyadmin) y crea una nueva base de datos vacía. Te sugerimos llamarla capycontrol_db o vad1.

3. Configuración del Entorno (Laravel)

3

Archivo de Configuración (.env)

Duplica el archivo .env.example que está en la raíz de la carpeta y renómbralo a .env. Edítalo para asegurar la conexión con la base de datos (y cambiar el driver de sqlite a mysql): 
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=capycontrol_db o vad1
DB_USERNAME=root
DB_PASSWORD=
4

Instalación de Dependencias, Base de Datos y Enlaces

Abre la consola de comandos (CMD o PowerShell) dentro de la carpeta de CapyControl y ejecuta secuencialmente: 
composer install
php artisan key:generate
php artisan migrate --seed
php artisan storage:link
Nota Importante: El comando --seed es crucial porque inyecta los datos maestros iniciales en el sistema (como el usuario Administrador y las configuraciones base).
El comando storage:link permite que las imágenes de los productos sean visibles públicamente.
5

Compilación de Recursos Frontend (Vite)

Para que el diseño del panel administrativo se vea correctamente, en la misma consola ejecuta: 
npm install
npm run build

4. ¡Sistema Listo!

🚀 CapyControl ha sido instalado exitosamente.
Puedes acceder al panel administrativo ingresando desde cualquier navegador a http://localhost/capycontrol/public/.

Credenciales por Defecto (si se ejecutó el Seeder):
Suelen ser definidas en los archivos DatabaseSeeder, usualmente:
Usuario: admin o admin@capycontrol.com
Clave: password o 12345678
