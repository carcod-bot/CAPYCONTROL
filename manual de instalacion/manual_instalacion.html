⚙️ Manual de Instalación: CapyControl (Backend)

Esta guía detalla paso a paso cómo desplegar el servidor central CapyControl en un entorno Windows usando XAMPP, establecer su seguridad y activar su sistema de licencias.

1. Requisitos Previos

  • XAMPP con PHP 8.2 o superior y MySQL/MariaDB activados.
  • Extensiones PHP requeridas: fileinfo, zip, mbstring, openssl.
  • Composer instalado globalmente en el servidor.
  • Node.js y NPM instalados (para compilar los estilos del panel).

2. Configuración de Seguridad en XAMPP (Contraseña MySQL)

Por defecto, XAMPP instala MySQL con el usuario root y sin contraseña. Por seguridad en un entorno de cliente, es fundamental establecer una contraseña.

1

Asignar contraseña a root

  1. Abre el Panel de Control de XAMPP y asegúrate de que Apache y MySQL estén corriendo.
  2. Entra a phpMyAdmin yendo a http://localhost/phpmyadmin.
  3. En el menú superior, haz clic en la pestaña Cuentas de usuarios.
  4. Busca el usuario root que tiene como nombre de host localhost y haz clic en Editar privilegios.
  5. Arriba haz clic en Cambio de contraseña.
  6. Escribe una contraseña segura y haz clic en Continuar.
Atención: Al cambiar la contraseña, phpMyAdmin se desconectará. Para solucionarlo y asegurar el sistema, ve a la carpeta C:\xampp\phpMyAdmin, abre el archivo config.inc.php y busca la línea $cfg['Servers'][$i]['auth_type'] = 'config';. Cámbiala a $cfg['Servers'][$i]['auth_type'] = 'cookie';. Guarda el archivo, recarga la página y phpMyAdmin te pedirá tu usuario (root) y la nueva contraseña para entrar de forma segura.

3. Despliegue de Archivos y Base de Datos

2

Copiar los archivos

Pega la carpeta entera del proyecto capycontrol dentro de la carpeta pública de tu servidor web (Usualmente C:\xampp\htdocs\capycontrol\).

4. Configuración e Instalación Automática

Hemos preparado un script ejecutable que automatizará la creación de la base de datos, la instalación de dependencias y la compilación de recursos.

4

Ejecutar instalar.bat y configurar .env

  1. Entra a la carpeta del sistema y haz doble clic en el archivo instalar.bat.
  2. Se abrirá una consola que descargará todas las dependencias. Luego, se pausará mostrando un mensaje de ACCIÓN REQUERIDA.
  3. Sin cerrar esa consola, abre el archivo .env en un editor de texto (como el bloc de notas) y configura tu base de datos: 
    DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=vad1
DB_USERNAME=root
DB_PASSWORD=TU_NUEVA_CONTRASEÑA

SESSION_DRIVER=file
CACHE_STORE=file
  4. Guarda y cierra el archivo .env.
  5. Vuelve a la consola negra y presiona ENTER. El script continuará y ejecutará automáticamente las migraciones y los enlaces de almacenamiento.
Licencia: El archivo .env ya viene preconfigurado con tu llave APP_INTEGRITY_HASH. ¡No modifiques esta llave o romperás la validación de la licencia!
Nota: El script instalar.bat también se encargará automáticamente de compilar todos los recursos visuales del panel (Vite/Node.js) para que no tengas que hacerlo a mano.

5. Activación de Licencia del Sistema

CapyControl cuenta con una protección anclada al hardware. El sistema estará bloqueado hasta ingresar una licencia válida.

7

Generar e Ingresar la Licencia

  1. Entra al sistema: http://localhost/capycontrol/public. Serás redirigido a la Pantalla de Activación.
  2. Copia el ID de Sistema mostrado en la pantalla.
  3. Modifica y guarda los campos de Organización y Sucursal con los datos reales del cliente.
  4. Abre el Generador de Licencias (Keygen) de CapyControl en tu PC de administrador.
  5. Ingresa el ID del sistema y escribe EXACTAMENTE el mismo nombre de Organización y Sucursal que pusiste en el cliente.
  6. Genera la llave y pégala en la pantalla del cliente para Activar.

6. Seguridad de Código (Ofuscación)

Para evitar alteraciones, se recomienda ofuscar con ionCube los siguientes archivos antes del despliegue:

  • app/Services/SysGuard.php
  • app/Http/Middleware/CheckLicense.php
  • app/Http/Controllers/LicenseController.php

7. ¡Sistema Listo!
